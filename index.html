01

일반 AHP 판단행렬 만들기

선택한 중요도 1~5를 넣고, 반대 방향에는 역수 1/a를 넣습니다.

02

AHP 가중치와 일관성비율 CR

각 행의 기하평균을 정규화해 가중치를 구하고, 그 가중치로 λmax를 근사합니다.

모든 비교를 완료하면 실제 계산값이 표시됩니다.
중요: CR은 삼각퍼지수에서 계산한 값이 아니라, 일반 AHP의 실수 판단행렬을 기준으로 계산합니다. 보통 CR ≤ .10이면 판단의 일관성이 수용 가능한 것으로 해석합니다.

04

퍼지 기하평균과 퍼지 가중치

각 행의 l, m, u를 각각 곱해 n제곱근을 구한 뒤, 전체 퍼지 기하평균 합의 역수를 곱합니다.

rᵢ = (∏lᵢⱼ)¹⁄ⁿ, (∏mᵢⱼ)¹⁄ⁿ, (∏uᵢⱼ)¹⁄ⁿ
W̃ᵢ = r̃ᵢ ⊗ (Σr̃ᵢ)⁻¹
05

비퍼지화하고 정규화하기

무게중심법으로 삼각퍼지수를 하나의 수로 바꾸고, 합이 1이 되도록 정규화합니다.

dᵢ = (lᵢ + mᵢ + uᵢ) / 3　→　wᵢ = dᵢ / Σdᵢ
