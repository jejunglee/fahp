# F-AHP 인터랙티브 학습실

이상형 월드컵처럼 두 항목을 비교하며 일반 AHP와 퍼지 AHP(F-AHP)의 계산 과정을 학습하는 한국어 웹사이트입니다.

## 주요 기능

- 특수교육 에듀테크 요인 3~5개 예제
- 모든 쌍에 대한 1~5 중요도 비교
- 일반 AHP 가중치 및 일관성비율(CR) 계산
- 삼각퍼지수 변환, 기하평균, 비퍼지화, 정규화 시각화
- 모바일 반응형 인터페이스

## 계산 방법

퍼지 척도는 수정 Buckley 5점 척도 `(1,1,1), (1,2,3), (2,3,4), (3,4,5), (4,5,6)`을 사용합니다. CR은 퍼지 판단값이 아니라 일반 AHP 실수 판단행렬을 기준으로 계산합니다.

## 실행

정적 웹사이트이므로 `index.html`을 브라우저에서 열면 바로 실행됩니다.
